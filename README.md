## 🌟 Featured Projects

### Day 01 — Tic-Tac-Toe Web Game

A browser-based Tic-Tac-Toe game built using Python Flask, HTML, CSS, and JavaScript.

**Features**
- Player-versus-player mode
- Computer opponent with difficulty levels
- Score tracking
- Undo and new-game options
- Sound effects and win celebrations
- In-game notifications and confirmation dialog
- Responsive, colorful interface

**Technologies:** Python, Flask, HTML, CSS, JavaScript

**Run locally**

1. Clone the repository:

   ```bash
   git clone https://github.com/vidyashreem46/30-Days-Coding-Challenge.git
   ```

2. Open the project folder:

   ```bash
   cd 30-Days-Coding-Challenge/Day01-TicTacToe
   ```

3. Install Flask:

   ```bash
   python -m pip install flask
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000/` in your browser.

**Project folder:** [`Day01-TicTacToe`](./Day01-TicTacToe/)

### Day 02 — KeyCraft Password Generator

A responsive password generator web app built with Python Flask, HTML, CSS, and JavaScript. It generates passwords using Python's `secrets` module.

**Features**
- Generate one or multiple passwords
- Choose password length (8–128 characters)
- Include or exclude uppercase letters, lowercase letters, digits, and symbols
- Option to exclude confusing characters
- Password strength estimate
- Copy individual passwords and regenerate passwords
- Temporary password history in the browser (up to 20 entries; cleared when the page is refreshed or closed)
- Responsive interface with a clean, light design

**Technologies:** Python, Flask, HTML, CSS, JavaScript

**Run locally**

1. Open the Day 02 folder:

   ```bash
   cd 30-Days-Coding-Challenge/Day-02-Password-Generator
   ```

2. Install Flask if it is not already installed:

   ```bash
   python -m pip install flask
   ```

3. Start the application:

   ```bash
   python app.py
   ```

4. Open `http://127.0.0.1:5000/` in your browser.

**Project folder:** [`Day-02-Password-Generator`](./Day-02-Password-Generator/)

> **Security note:** Generated passwords are handled by the app locally. Avoid using a development server with debug mode enabled for a public deployment, and do not share real passwords.
